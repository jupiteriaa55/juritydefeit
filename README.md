# Весёлый Могильщик

2.5D мультяшный **тайм-менеджер симулятор кладбища**. Главный герой — мистер
Юпитер, превращающий родовые земли в место последнего пристанища. Игрок
принимает заказы родственников, копает могилы, выбирает надгробия, цветы и
дорожки, укладывается в срок и в бюджет, гонит собаку искать кристаллы.

## Стек

- **Three.js** — 3D-рендер с ортографической камерой сверху и низкополигональной
  «мультяшной» геометрией (плоский шейдинг, процедурные Canvas-текстуры).
  «Похоже на Godot, но легче» — всё работает в браузере без тяжёлых ассетов.
- **Vite** + `vite-plugin-pwa` — сборка и PWA (offline, manifest, service worker).
- **Capacitor** — обёртка для **Android (.apk)**.

## Возможности (MVP)

- Карта 200 × 200 клеток. Камера: drag для пана, кнопки **+ / −** или
  колесо/щипок — зум. WASD/стрелки — тоже.
- Цикл заказа: имя усопшего, желаемый стиль, бюджет, дни → выкопать → засыпать
  → надгробие → выгравировать имя → сдать заказ. Слишком шикарно — родственники
  не оплатят сверх лимита, слишком скромно — откажутся платить.
- Каталог: 6 типов надгробий и крестов, 4 цвета цветов, дорожки, сосны,
  скамьи, фонари, ограды. Для каждого — мультяшная процедурная текстура.
- Помощник — собака. Гуляет, иногда находит кристаллы (бонус к стилю).
- Bonus за соседство: цветы и дорожки рядом с могилой повышают итог.
- День заканчивается кнопкой «Завершить день»; срок заказа уменьшается.

## Запуск

```bash
npm install
npm run dev   # http://localhost:5173
```

## Сборка PWA

```bash
npm run build
npm run preview   # проверка production-сборки
```

`dist/` содержит готовый PWA: можно положить на любой статический хостинг.

## Сборка APK для Android

```bash
npm run build
npx cap add android   # один раз
npx cap sync android
cd android && ./gradlew assembleDebug
# APK: android/app/build/outputs/apk/debug/app-debug.apk
```

## Управление

| Действие | Управление |
| --- | --- |
| Выбрать инструмент | клик по карточке справа |
| Действие в клетке | ЛКМ по клетке |
| Переместить камеру | drag (ЛКМ) или WASD/стрелки |
| Зум | кнопки **+ / −**, колесо мыши, пинч |
| Снять инструмент | **Esc** |
| Позвать собаку | **D** или инструмент «Позвать собаку» |
| Завершить день | кнопка «Завершить день ▶» |

## Как устроено

```
src/
  main.js          — точка входа, игровой цикл
  world.js         — сетка 200×200, фоновое поле, постановка/удаление клеток
  cameraControl.js — ортокамера 2.5D, пан/зум/жесты
  characters.js    — мистер Юпитер и его собака
  items.js         — каталог объектов и инструментов + меш-фабрики
  textures.js      — процедурные мультяшные Canvas-текстуры
  orders.js        — генерация и оценка заказов
  ui.js            — DOM-привязки (инструменты, тосты, модалки, заказ)
```

Расширение тривиально: добавить запись в `ITEM_DEFS` и фабрику в
`MAKERS` в `src/items.js`, после чего объект сразу появится в панели.
